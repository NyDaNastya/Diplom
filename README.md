📋 О проекте
Веб-сайт для салона красоты — это современный, адаптивный сайт-визитка, разработанный для привлечения новых клиентов, информирования об услугах и мастерах, а также для удобной связи с салоном.

Проект выполнен в рамках дипломной работы студенткой группы ИС 22-01 Красноярского колледжа отраслевых технологий и предпринимательства.

✨ Функциональные возможности
Для посетителей сайта
📱 Адаптивный дизайн — корректное отображение на всех устройствах (ПК, планшет, смартфон)

🏠 Главная страница — приветственный баннер и общая информация о салоне

💇 Каталог услуг — полный перечень услуг с ценами и описаниями

👩‍🎨 Информация о мастерах — знакомство с командой профессионалов

📞 Контакты — актуальная контактная информация (телефон, адрес)

📝 Форма обратной связи — быстрая запись на услугу

🗺️ Схема проезда — удобное расположение салона на карте

Для администратора
📊 Управление контентом — возможность обновлять информацию об услугах и ценах

📨 Обработка заявок — получение уведомлений о новых записях от клиентовм
